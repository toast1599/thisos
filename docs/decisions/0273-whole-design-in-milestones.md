# 0273. The roadmap reaches the whole design through milestones

- **Status:** Accepted
- **Date:** 2026-10-20

## Context

The roadmap ends when every Accepted decision that isn't later work is built and tested, with a first release ([0222](0222-roadmap-to-first-release.md)). Nothing before that is tagged or meant to run as a whole system, and step 1 showed how much a step can hold that the plan didn't see ([0272](0272-roadmap-reopened.md)).

## Options

1. **The whole design, in milestones.**
2. **The whole design, as one release,** as 0222 has it.
3. **A smaller first release,** and the rest planned after it.

## Decision

Option 1.

- The roadmap still ends at the whole design and a first release, as 0222 says.
- On the way, it reaches milestones. Each is a working system, tagged when it's done ([0274](0274-milestone-definition.md)), in the order [0275](0275-eight-milestones.md) gives.
- This amends 0222, which had nothing tagged before the end.

## Consequences

- **Progress is a system that runs,** at each milestone.
- **Each milestone teaches the next** what building found.
- **The first release stays the only image meant for use** ([0284](0284-development-images.md)).
